# Khushi Kumari — Personal Portfolio

A modern and responsive personal portfolio website designed to showcase my skills, projects, and journey as a frontend developer. This portfolio reflects my passion for clean UI design, responsive layouts, and interactive web experiences.

---

## About the Project

This portfolio website was created to build my online presence and display my work in a professional way. The website highlights my technical skills, projects, services, and contact information with a clean and modern interface.

The project focuses on:

- Responsive web design
- Smooth user experience
- Modern UI styling
- Interactive animations
- Frontend development skills

---

## Features

- Fully responsive design
- Modern user interface
- Animated typing effect using Typed.js
- Interactive custom cursor
- Particle background animation
- Smooth scrolling navigation
- Skills progress bars
- Portfolio projects section
- Contact form UI
- Mobile-friendly navigation menu

| Technology | Purpose |
